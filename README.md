## Featured Projects

### CareBridge
AI-powered healthcare report management system. Users can sign up, upload medical report images, extract report text using OCR, simplify medical language with Gemini AI, and manage medicine reminders.

### Mudra Detector
Computer vision project that recognizes Bharatanatyam hand mudras in real time using OpenCV, MediaPipe, and machine learning. It detects hand landmarks from a webcam feed, classifies the mudra, and displays the prediction through a Flask web interface.

### SheCARE – Women’s Health Platform
- React and Vite-based responsive health education platform.
- Designed with a clean UI/UX and scalability in mind.
- Future scope includes an AI assistant and OCR-based medical report module.

### Fruit Ninja AI Clone
- Real-time hand tracking game using computer vision.
- Gesture-based interaction system.
- Built using Python, OpenCV, and MediaPipe.

### Breast Cancer Prediction System
- Machine learning classification model using Scikit-learn.
- Includes data preprocessing, training, and evaluation pipeline.

### Netflix Data Analysis
- Exploratory data analysis on a global Netflix dataset.
- Insights generated using Pandas, Matplotlib, and Seaborn.
