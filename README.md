VisionPlot
Computer Vision-Based Graph Digitizer
A Streamlit application that converts plotted graphs into usable numerical data. It combines image preprocessing, thresholding, morphology, edge detection, Hough-based line/axis detection, OCR, and pixel-to-coordinate calibration to extract curve points from graph images.
Highlights
- Image enhancement and filtering to improve graph readability
- Axis detection and manual origin/scale calibration
- Curve extraction and pixel-to-data coordinate conversion
- Export extracted points as CSV and visualize the resulting data
- Compare linear, quadratic, and cubic curve fits using metrics such as R², RMSE, and MAE
Tech Stack
Python OpenCV Streamlit NumPy Pandas Tesseract OCR Matplotlib Scikit-learn

<h2 align="center">Additional Machine Learning Projects</h2>

CrediFraud — Adaptive Credit Card Fraud Detection
An adaptive machine learning system designed to detect fraudulent credit card transactions under severe class imbalance and changing transaction patterns.
The project uses the ULB Credit Card Fraud Detection dataset, containing 284,807 transactions, including 492 fraudulent transactions.
Multiple classification approaches are evaluated, including:
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost
- Adaptive SGD-based classification
Key Features
- Handles severe class imbalance using SMOTE
- Uses XGBoost for high-performance classification
- Implements an adaptive SGDClassifier
- Monitors potential concept drift
- Compares multiple machine learning models
- Provides fraud-risk predictions through a Streamlit interface
- Categorizes transactions into Low, Medium, and High Risk
Tech Stack
Python Pandas NumPy Scikit-learn XGBoost SMOTE Matplotlib Streamlit
