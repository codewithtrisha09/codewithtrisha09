## 📊 Data Science & ML

### 💳 CrediFraud — Adaptive Credit Card Fraud Detection

Detects fraud under **severe class imbalance and drifting transaction patterns** using the ULB dataset (284,807 transactions, only 492 fraudulent).

- Compares Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, XGBoost and an adaptive SGD classifier
- Handles imbalance with **SMOTE**
- Monitors **concept drift**
- Streamlit app that labels transactions **Low / Medium / High risk**

`Python` `Scikit-learn` `XGBoost` `SMOTE` `Streamlit`

[![Repo](https://img.shields.io/badge/View%20Repo-181717?style=flat-square&logo=github)](https://github.com/codewithtrisha09/CreditCardFraudDetection)

**More:** 🎗️ Breast Cancer Prediction (classification pipeline) · 🎬 Netflix Data Analysis (EDA on content trends)
